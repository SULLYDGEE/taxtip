# TaxTip — site

Pages publiques de l'app iOS TaxTip (App Store id 6761360591), servies par GitHub Pages
sur https://sullydgee.github.io/taxtip/.

- `calcul-taxes/` : calculateur de taxes (TPS, TVQ, TVH) et de pourboire, avec les taux
  de l'app (`src/engines/taxEngine.ts` du dépôt taxtippro, vérifiés le 9/10/2026).

La source de la page vit aussi dans `taxtippro/docs/web/calcul-taxes/`. Si les taux
changent dans l'app, les reporter ici.
